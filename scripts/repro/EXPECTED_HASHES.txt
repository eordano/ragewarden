# Release hashes, one row per artifact:
#   <artifact-name> <target-triple-or-flavor> <b3sum-hex>
#
# rageterm: the stripped release binary. ragemanifest: pkg/ragemanifest_bg.wasm.
# ragedroid: the unsigned APK with its entries re-emitted sorted, with constant
# timestamps and without the signing block (normalize_apk in verify-ragedroid.sh).
#
# A row is written by `scripts/repro/verify-<artifact>.sh --update-expected` on a
# release tag, and only after two builds of that tag from different paths agreed.
# Until a release records one, the verify scripts check the build by building it
# twice from two fresh trees and comparing.
